# Data Plan

This project will use a public construction safety / PPE image dataset.

## Planned Classes
- Person
- Hard hat / helmet
- Safety vest

## Data Source
The dataset will come from a publicly available source such as Kaggle or another computer vision dataset repository.

## Purpose
The images will be used to train and evaluate an object detection model that identifies construction workers and visible safety equipment.

## Notes
The dataset will be reviewed before training to make sure the images and labels are appropriate for the project.
